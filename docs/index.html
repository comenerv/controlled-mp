A small, curated shelf of Claude Code skills — starting with a discounted cash flow valuation tool.

$ /plugin marketplace add comenerv/controlled-mp

What this is

Claude Code can load extra abilities — called skills — that teach it a specific workflow, like turning a spreadsheet of financial filings into a valuation model. A plugin marketplace is just a git repository that lists which skills are available and where to fetch them from.

controlled-mp is that repository: one marketplace, currently bundling one plugin. As more skills get added here, each gets its own entry below without changing how you install.

Install

  1. Point Claude Code at this marketplace.

    /plugin marketplace add comenerv/controlled-mp

  2. Install the plugin you want from it.

    /plugin install npv-portfolio-valuation@controlled-mp

  3. Pull in changes later, any time the catalog below is updated.

    /plugin marketplace update

This repo is private. The add step needs GitHub access to comenerv/controlled-mp under the credentials Claude Code / git is already authenticated with.

Catalog

Skill npv-portfolio-valuation

NPV Portfolio Valuation

Turns raw 10-K / 10-Q line items into a discounted cash flow valuation — per holding, and rolled up across a portfolio.

Triggers on

  • A CSV of 10-K/10-Q line items — revenue, operating cash flow, capex, debt, cash, shares outstanding
  • Requests for intrinsic value, NPV, DCF, or “what is this company / portfolio worth”
  • Multiple holdings in one file, for a portfolio-level roll-up

Method

  • Normalizes quarterly filings to an annual / trailing-twelve-month basis
  • FCF = operating cash flow − capex, with historical growth (CAGR) as the default projection rate
  • 5-year explicit projection, Gordon Growth terminal value, discounted at a stated rate
  • Bridges enterprise value to equity value via debt and cash, then to value per share
  • States every assumption in the output, and flags negative/volatile FCF, thin history, or missing data rather than forcing a number

Why the later years count less

Each year's cash flow is discounted back to today at the chosen rate, so a dollar five years out is worth less than one next year. The dashed bar is the present value of everything after year five (Gordon Growth terminal value) — usually the single largest piece of the valuation, and the most assumption-sensitive.

Adding a plugin

  1. Give it its own directory with a .claude-plugin/plugin.json and a skills/ folder — or extend this layout if controlled-mp stays single-plugin.
  2. Add an entry for it under plugins in .claude-plugin/marketplace.json.
  3. Add a card for it to the catalog above.
